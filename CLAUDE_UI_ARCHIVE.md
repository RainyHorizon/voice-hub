# Claude UI Archive

This branch preserves the Claude-generated frontend experiment captured on September 27, 2026.

- It is an archival comparison branch, not the production branch.
- Application data, environment files, API keys, databases, audio files, and logs are not included.
- HarmonyOS Sans SC font binaries are intentionally excluded because they require the user to obtain and accept the upstream font license. The included build script can regenerate local font assets when authorized.
- The production frontend continues on `main`.

To compare the implementations on GitHub, compare `main...archive/claude-ui-2026-09-27` or inspect the same page files on both branches.
